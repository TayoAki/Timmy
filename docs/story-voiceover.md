# "Monday, 8:12": voiceover script for ElevenLabs

The narration for the story demo (`?story`, script in `src/story/script.ts`) and the cinematic intro (`?intro`). The lines are written to be heard rather than read: numbers are spelled out, prices are rounded where the screen shows the exact figure, and each line fits its scene.

## Voice

- **Character:** a warm, unhurried narrator, mid-30s, conversational. A slight smile, never salesy. Think short documentary, not a commercial.
- **Pace:** about 150 words a minute. Pauses are written in.
- **Model:** Eleven Multilingual v2 (or Flash v2.5). Both read `<break time="0.4s" />` tags, up to 3 seconds each.
- **Starting settings:** Stability 50, Similarity 75, Style 10, Speaker boost on. Raise Stability if takes vary too much between scenes.
- **Eleven v3 or v4:** these don't support `<break>` tags. Delete them and let the punctuation carry the pauses. An ellipsis (…) or a new line gives a longer pause.
- **One clip per scene:** name the files `story-00.mp3` to `story-25.mp3`, and `intro-1.mp3` to `intro-3.mp3`. Short clips are easy to retake, and the player can later hold each scene until its clip ends.

Pronunciation: Timmy, Taylor, Dana, Marcus and Acme read correctly as written. "CFO" is read as letters. "Okay" is spelled out so it isn't read as "O-K".
